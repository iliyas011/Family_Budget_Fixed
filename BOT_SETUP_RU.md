# Создание своего Telegram-бота

1. Откройте https://t.me/BotFather — официальный бот Telegram с отметкой подлинности.
2. Нажмите Start и отправьте /newbot.
3. Укажите название: Family Budget — коды.
4. Укажите username, например family_budget_isa_bot. Он должен заканчиваться на bot. Если занят, добавьте цифры.
5. BotFather выдаст токен. Не пересылайте его в чат, не публикуйте и не добавляйте в JavaScript.
6. В папке рядом с app.py скопируйте .env.example и назовите копию .env.
   В Windows включите «Показывать расширения имён файлов», чтобы не получить .env.txt.
7. Откройте .env Блокнотом. После TELEGRAM_BOT_TOKEN= вставьте токен без пробелов.
   TELEGRAM_BOT_USERNAME можно оставить пустым: имя определяется автоматически.
8. Закройте старое окно сервера и запустите start.bat. Для macOS/Linux: python3 app.py.
9. Откройте http://127.0.0.1:8000. Зарегистрируйтесь с номером +7...
10. В аккаунте найдите блок Telegram, введите текущий пароль и нажмите «Привязать Telegram».
11. Нажмите появившуюся ссылку «Открыть бота» и Start в Telegram.
12. Вернитесь на сайт. Должно появиться «Telegram привязан».

Проверка: выйдите, выберите «Забыли пароль?», введите свой номер с кодом страны.
Код из 4 цифр придёт в ваш личный чат с ботом. Введите его на сайте и задайте новый пароль.

Привязка нужна один раз. Бот не ищет пользователей по номеру и не отправляет SMS.
Номер на сайте помогает найти учётную запись; адрес Telegram определяется по вашей привязке.
Регистрацию и вход можно использовать без бота, но восстановление через Telegram требует настройки.

Если бот недоступен: проверьте токен и интернет, перезапустите сервер.
Если этим ботом уже пользуется другая программа, остановите её. Активный webhook нужно отключить.
Если токен попал к другому человеку, замените его через /revoke в BotFather.
