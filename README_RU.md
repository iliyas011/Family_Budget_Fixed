# Family Budget — исправленный вход и восстановление

Нужен Python 3.10 или новее. Дополнительные пакеты не требуются.

## Запуск

1. Распакуйте всю папку. Не переносите HTML отдельно от папки static.
2. В Windows запустите start.bat либо в терминале из этой папки: python app.py
3. Откройте http://127.0.0.1:8000/login
4. Нажмите Create account, задайте логин (3–40 символов), номер с кодом страны (например +7 777 123 45 67) и пароль (8–128 символов).
5. После регистрации вход выполняется автоматически. Аккаунты сохраняются в data/users.sqlite3.

HTML нельзя запускать двойным щелчком или через Live Server: API работает в app.py.
Сервер предназначен для локального учебного использования. Для доступа нужен именно localhost/127.0.0.1.
Точный способ прежнего запуска неизвестен; причина сбоя на вашем компьютере ещё не воспроизведена.

## Telegram

1. В Telegram откройте официальный @BotFather, выполните /newbot и создайте бота.
2. Скопируйте .env.example в .env рядом с app.py.
3. В .env заполните TELEGRAM_BOT_TOKEN. Имя бота определится автоматически; TELEGRAM_BOT_USERNAME можно оставить пустым.
4. Перезапустите python app.py. Одновременно запускайте только один экземпляр сервера с этим ботом.
5. Войдите в свой аккаунт. Внизу страницы введите текущий пароль и нажмите «Привязать Telegram».
6. Откройте появившуюся ссылку и нажмите Start в личном чате с ботом за 5 минут.
7. Вернувшись на сайт, вы увидите «Telegram привязан».

Для восстановления выйдите, нажмите «Забыли пароль?», введите логин или номер.
Введите полученный код из 4 цифр и новый пароль дважды.
Код действует 5 минут, допускает 5 попыток и используется один раз.
При повторной отправке старый код отменяется. После сброса старый пароль и сеансы этого пользователя недействительны.
Нельзя привязать Telegram, зная только чужой логин: нужны активный сеанс и текущий пароль.
Без заранее привязанного Telegram самостоятельное восстановление невозможно.
Не передавайте ссылку привязки другим людям. Один Telegram привязывается к одному аккаунту.

Бот получает команды методом getUpdates, поэтому публичный адрес/webhook не требуется.
Нужен доступ к api.telegram.org. Для ранее настроенного webhook его сначала нужно отключить.
При перезапуске сайта незавершённые коды/ссылки истекают; запросите новые. Привязка Telegram сохраняется.
Реальная отправка требует вашего токена и не проверена без него.

## Старые данные

Пакет не содержит ваши личные базы. Для сохранения аккаунтов и записей скопируйте существующую папку data
в эту папку ПЕРЕД запуском. Сделайте резервную копию перед заменой файлов.
Схема пользователей расширяется автоматически таблицей telegram_accounts.
Все аккаунты по-прежнему используют один общий семейный бюджет — это свойство исходного учебного проекта.

## Номер телефона

Для новых аккаунтов номер обязателен и уникален. Пробелы, скобки и дефисы удаляются при сохранении.
Например, +7 (777) 123-45-67 и +77771234567 — один номер.
Вход и восстановление принимают логин или номер с + и кодом страны.
Номер служит идентификатором аккаунта; владение номером не подтверждается SMS.
Telegram-бот не ищет людей по номеру: коды идут только в заранее привязанный личный чат.
Старые аккаунты продолжают работать по логину без номера; существующие базы обновляются автоматически.
Для привязки: войдите, введите текущий пароль в блоке Telegram, нажмите «Привязать Telegram»,
затем «Открыть бота» и Start. Это нужно сделать один раз.
