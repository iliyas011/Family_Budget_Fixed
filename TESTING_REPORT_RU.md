# Money Report — Testing, Analytics & Integration

## Реализованный результат

Добавлены фильтры отчёта: месяц, начальная дата, конечная дата, тип операции, категория, минимальная сумма, максимальная сумма, поиск по заметке. Есть четыре варианта сортировки и сброс фильтров. Фильтры работают совместно (AND); месяц и диапазон дат пересекаются. Границы дат и сумм включаются. Пустые поля не ограничивают отчёт. Поиск нечувствителен к регистру и ищет именно в заметках; категории выбираются отдельно.

Список операций, количество записей, доходы, расходы, баланс и обе диаграммы используют один отфильтрованный набор. Без фильтров показывается весь бюджет. Сортировка меняет порядок списка, но не суммы.

Добавлено редактирование всех полей операции через кнопку Edit и форму ввода; Cancel edit отменяет режим редактирования. После сохранения и удаления отчёт обновляется с текущими фильтрами. Некорректные изменения не сохраняются. Неверный ID возвращает 400; отсутствующая операция — 404. Редактирование и удаление требуют авторизации и проходят существующую проверку Origin.

## Запуск на Windows

Открыть терминал в папке с app.py:

```bat
python -m unittest discover -v
```

Только основной набор с новыми тестами:

```bat
python -m unittest test_app test_reports -v
```

Только 23 новых теста:

```bat
python -m unittest test_reports -v
```

Запуск сайта:

```bat
python app.py
```

Открыть http://127.0.0.1:8000. Использовать свой существующий аккаунт.

## Проверки и ограничения

Автоматические unit и HTTP integration тесты пройдены. Синтаксис JavaScript проверен через node --check. Браузерный smoke test пытался запуститься, но Chromium завершился из-за запрета socket() в среде. Поэтому визуальная проверка и клики по интерфейсу здесь не подтверждены.

Перед демонстрацией: добавить операцию, изменить её сумму и дату, применить её месяц, выбрать пустой месяц, сбросить фильтры, удалить запись. Проверить совпадение списка, карточек и диаграмм, а также вид страницы на телефоне.

Существующая модель проекта — общий семейный бюджет для всех вошедших пользователей. Это не раздельные персональные бюджеты. Отчёт фильтруется на сервере; текущая реализация сначала читает операции из SQLite, затем фильтрует их в Python. Для больших объёмов потребуется SQL-фильтрация и пагинация.
